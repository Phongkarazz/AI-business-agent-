# Quán Cafe Phố Việt
- File Excel gồm 2 sheet: `DonHang` (đơn hàng bán lẻ hàng ngày) và `DanhMucMon` (menu đồ uống).
- Doanh thu thực tế chỉ tính các đơn có `trang_thai = 'Hoàn thành'` (loại trừ `'Đã hủy'` và `'Trả lại'`).
- Quán không ghi thông tin khách hàng hay tồn kho nguyên liệu trong file này.
